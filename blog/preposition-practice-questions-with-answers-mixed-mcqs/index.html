Preposition Practice Questions with Answers: Mixed MCQs for Class 12 and Competitive Exams

Practise 30 mixed preposition MCQs with answers and reasons for Class 12 and competitive exams, plus memory shortcuts, a cloze passage and a 7-day plan.

Reading about prepositions is easy. Using them under exam pressure is a different game. That's why the fastest way to improve is to practise questions, check every answer and learn from every mistake.

This post gives you 30 mixed multiple-choice questions on prepositions, built for Class 12 students and SSC, bank, railway and state exam aspirants. They cover time and place, appropriate prepositions, confusing pairs and error spotting. Every question has an answer and a reason, and there's a memory-shortcut cheat sheet before the harder sets.

A note on the questions: These are original sentences based on common exam patterns. They are not copied from any particular year's paper, and no exam year is attached to them.

How to use this practice set:

  3. Check the answer key and mark your score for each set.
  4. For every wrong answer, write the sentence and correct pair in your notebook.
  5. Retake the set after three days.

Five rules to read before you start

Read these five lines before the first question. They solve many of the questions below.

  1. Clock time takes at, a day or date takes on, and a month, year or season takes in.
  2. Fixed pairs beat logic. Learn the pair, not just the sentence.
  3. Rank words (senior, junior, superior, inferior) and prefer take to.
  4. When to is a preposition, a following verb takes -ing: “looking forward to meeting”.
  5. In error spotting, check every preposition against its partner word before choosing “No error”.

Memory shortcuts cheat sheet (revise before Set B)

Take two minutes to review these memory aids. Screenshot the table if useful.

TopicMemory shortcut
Time: at / on / inAT the clock, ON the calendar day, IN the long stretch (month, year, season).
Place: at / on / inP-S-S: Point = AT, Surface = ON, Space = IN. This is a memory aid, not an absolute rule for every context.
Rank words and “prefer”Senior, junior, superior, inferior and prefer take TO in standard constructions.
Congratulate / thankCongratulate someone ON an achievement; thank someone FOR something.
SufferSuffer FROM an illness or problem.
Insist / depend / relyInsist ON, depend ON, rely ON.
Verbs that need no helperD-C-R-E: discuss, comprise, reach and enter usually take a direct object without an added preposition in these meanings.
Between / amongBetween is often used for two; among is often used for a group. Usage can vary with the relationship being described.
Since / forFOR + duration; SINCE + starting point.
Beside / besidesBESIDE = next to; BESIDES = in addition to.
By / untilBY = deadline; UNTIL = continuation up to a time.
Look forward to ___In “look forward to”, TO is a preposition, so use a noun or an -ing form.

  2. She is senior than (A) / me by (B) / two years. (C) / No error (D)
  3. He congratulated me (A) / for my (B) / excellent result. (C) / No error (D)

Bonus Set E: Mini cloze passage (8 blanks)

Read the full paragraph before filling each blank. This bonus set is not included in the 30-question score.

Last Sunday, our school organised a science exhibition (1) ___ the main hall. The programme began (2) ___ 10 am, and students from many schools participated (3) ___ it. I was responsible (4) ___ one project, and my teacher congratulated me (5) ___ my effort. I had been preparing (6) ___ two weeks, and I was proud (7) ___ my team. We are looking forward (8) ___ the next exhibition.

2) c — on (date)
3) c — in (season)

5) c — in (city)

7) c — on (day + part of day)
8) a — in (enclosed space)

Set B

10) b — congratulate on
11) b — suffer from
12) a — consist of
13) a — grateful to a person; grateful for a thing
14) b — adhere to

Set C
19) b — among (a group of three)
20) c — since (starting point)
21) b — for (duration)
22) b — besides (in addition to)
23) b — into (movement inside)
24) b — by (deadline)

Set D
25) A — “discussed about” should be “discussed”; discuss takes a direct object here.
26) A — “senior than” should be “senior to”.
27) B — “congratulated me for” should be “congratulated me on”.
28) C — “since ten years” should be “for ten years”.
29) D — no error: “angry with the students for being late” is acceptable.
30) B — “to meet” should be “to meeting”; in “look forward to”, to is a preposition.

Keep an error log (it takes five minutes)

Every wrong answer is a useful lesson. Make a three-column log: the sentence, the correct answer and the reason. For example: “She is senior than me | senior to me | rank words take TO”.

Read the log once a week. Repeated errors show you which pairs to learn first. This is more useful than answering many new questions without reviewing mistakes.

How Class 12 students and competitive aspirants should use this set

If you're a Class 12 student, use this set to build accuracy in writing. After each set, write five original sentences using the pairs you got wrong. Practising them in context can help you use them in letters, essays and reports.

If you're preparing for SSC, banking, railway or state exams, practise speed as well as accuracy. Take Sets B, C and D as a timed block of 22 questions. Allow 12–15 minutes, then use the answer key to identify the question types that cost you time and marks.

Frequently asked questions

How many preposition questions should I practise every day?

Ten is a useful target. Solve them, check the answers and write down mistakes. Ten careful questions can teach more than fifty rushed ones.

Should I read the options before I read the sentence?

Read the sentence first and think of your own answer. Then look at the options. This can stop the options from steering you in the wrong direction.

What should I do if two options look correct?

Check the meaning. Ask whether it's a point or a duration, two or a group, movement or position. If it's a fixed pair, trust the established usage rather than sound alone.

Is “No error” the right answer in error-spotting questions?

Sometimes. Treat it as a conclusion, not a default. Check every preposition with its partner word before choosing it.

How long should this practice set take?

As a rule of thumb, allow 15–20 minutes for all 30 questions. If you take longer at first, that's fine. Speed comes after accuracy.

Practice makes the pattern permanent

Thirty questions are only the start. Retake this set in three days, then again in a week. Track your errors so you know which pairs still need work.
